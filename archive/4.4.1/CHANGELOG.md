**DLA OSÓB AKTUALIZUJĄCYCH FG ZE STARSZYCH WERSJI**
Z powodu zmiany systemu przechowywania danych - potrzebna jest zmiana sekcji `data-type` w configu. Notacja:
```
data-type: 
  flat: true/false
  mysql: true/false
```

Musi zostać zmieniona na:
```
data-type: FLAT/MYSQL
```

Nie ma możliwości wyboru kilku typów zapisu - można wybrać albo **FLAT**, albo **MYSQL**
