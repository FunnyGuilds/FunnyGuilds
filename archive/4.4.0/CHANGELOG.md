# FunnyGuilds Tribute (#4.4.0)

- **Tag:** 4.4.0
- **Published:** 2019-01-29T22:59:58Z
- **GitHub release:** https://github.com/FunnyGuilds/FunnyGuilds/releases/tag/4.4.0

---

**Zmiany:**
* Dodano wsparcie wersji 1.13+
* Dodano możliwość nadawania nagród dla graczy za założenie pierwszej gildii na serwerze
* Dodano możliwość nałożenia dodatkowej ochrony na gildie, gdy jest taka potrzeba
* Dodano możliwość użycia jajka smoka jako środka gildii
* Dodano wsparcie PlaceholderAPI
* Poprawiono działanie asyst
* Naprawiono wiele błędów związanych z gildiami, w tym z zapisem oraz odczytem danych z dysku
* Struktura projektu została zmodyfikowana, od teraz wiele akcji związanych z gildiami są wykonywane za pomocą API zapytań
* Zaktualizowano biblioteki w projekcie
* Dużo poprawek, stabilizujących ogólne działanie pluginu oraz poprawiających wydajność

Przypominam również o tym, że jako społeczność **NIE MUSICIE** czekać na stabilne wydanie pluginu FunnyGuilds - wersje deweloperskie pluginu są dostępne [tutaj](https://ci.insertt.pl/job/FunnyGuilds/).

**Wymagania:**
* Spigot 1.8.8+
* Java 8+
