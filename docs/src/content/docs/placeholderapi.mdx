:::tip[Dodawanie własnych placeholderów]
Jeśli chcesz użyć placeholder'ów we własnym pluginie wykorzystując PlaceholderAPI, zapoznaj się z tym poradnikiem: [Adding placeholders to PlaceholderAPI](https://github.com/PlaceholderAPI/PlaceholderAPI/wiki/Hook-into-PlaceholderAPI#adding-placeholders-to-placeholderapi).
:::

FunnyGuilds daje możliwość użycia placeholder'ów w innych pluginach, które obsługują wtyczkę [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/).

### Zmienne gracza

- `%funnyguilds_player%`
- `%funnyguilds_ping%`
- `%funnyguilds_ping-format%`
- `%funnyguilds_points%`
- `%funnyguilds_points-format%`
- `%funnyguilds_kills%`
- `%funnyguilds_deaths%`
- `%funnyguilds_assists%`
- `%funnyguilds_logouts%`
- `%funnyguilds_kdr%`
- `%funnyguilds_position-typ%`
- `%funnyguilds_guild-position%`
