### Lista graczy na serwerze

Lista graczy, inaczej „TabList", służy do pokazywania informacji o gildii, graczu, serwerze, topce itd. Możesz zmienić jej wygląd za pomocą konfiguracji (pliki `tablist.yml` oraz `messages.yml`). Tutaj opisano dokładnie wszystkie dotyczące jej ustawienia.

Zanim rozpoczniesz, trzy rady:
- Dobrym edytorem tekstu do zmieniania konfiguracji jest [Notepad++](https://notepad-plus-plus.org/downloads/) — posiada podświetlanie składni, co bardzo ułatwia pracę.
- Aby szybko poruszać się po konfiguracji i znaleźć odpowiednie linijki, użyj skrótu `CTRL + F`.
- Po przesłaniu nowej konfiguracji nie przeładowuj serwera przez `/reload`! **Użyj komendy `/funnyguilds reload` lub zrestartuj serwer.**

---

### Podstawowe ustawienia (`tablist.yml`)

W sekcji `cells:` możesz ustawić wygląd wierszy tablisty. Można je numerować **od 1 do 80**. [Schemat numeracji tablisty](#schemat-numeracji-tablisty) pokazuje, w jaki sposób są numerowane.

```yml
cells:
  1: '&7Nick: &b{PLAYER}'
  2: '&7Ping: &b{PING}'
  3: '&7Punkty: &b{POINTS}'
  4: '&7Zabojstwa: &b{KILLS}'
  5: '&7Smierci: &b{DEATHS}'
  6: '&7KDR: &b{KDR}'
  7: '&7Gildia: &b{G-NAME}'
  9: '&7TAG: &b{G-TAG}'
  10: '&7Punkty gildii: &b{G-POINTS-FORMAT}'
  11: '&7Pozycja gildii: &b{G-POSITION}'
  12: '&7Liczba graczy online: &b{G-MEMBERS-ONLINE}'
  21: '&7Online: &b{ONLINE}'
  22: '&7TPS: &b{TPS}'
  41: '&bTop 3 Gildii'
  42: '&71. &b{GTOP-1}'
  43: '&72. &b{GTOP-2}'
  44: '&73. &b{GTOP-3}'
  61: '&bTop 3 Graczy'
  62: '&71. &b{PTOP-1}'
  63: '&72. &b{PTOP-2}'
  64: '&73. &b{PTOP-3}'
```

### Nagłówek i stopka (`tablist.yml`)

Nagłówek i stopka tablisty zostały zaprezentowane w [Schemacie numeracji tablisty](#schemat-numeracji-tablisty) (nagłówek `header`, stopka `footer`); możesz zmienić ich wygląd w pliku `tablist.yml`.

```yml
# Wyglad naglowka w liscie graczy.
header: '&7FunnyGuilds &b4.9.3 Tribute'
# Wyglad stopki w liscie graczy.
footer: '&c&lWiadomosci braku (pokazujace sie, gdy gracz nie ma gildii) mozna zmienic w pliku messages.yml!'
```

Aby dodać kilka linijek do nagłówka lub stopki, użyj znaku `|`, a następnie wprowadź kolejne linijki poprzedzając je dwiema spacjami:

```yml
# Wyglad stopki w liscie graczy.
footer: |
  linijka 1
  linijka 2
```

### Stronicowanie (`tablist.yml`)

Od wersji 4.10.0 dostępne jest stronicowanie tablisty. Konfiguracja wygląda bardzo podobnie jak w przypadku zwykłej tablisty — każda strona jedynie nadpisuje główną, a w przypadku braku wartości na stronie zostanie wyświetlona wartość ze zwykłej sekcji *cells/header/footer*. Liczba cykli (`cycles`) określa, jak długo dana strona będzie widoczna (1 cykl = 1 odświeżenie tablisty; częstotliwość odświeżania można zmienić, ustawiając wartość `update-interval` w `tablist.yml`). Można dodać nieskończenie wiele stron (ale lepiej zachować umiar 😉).

```yml
pages:
- cycles: 10
  cells:
    42: ' &b&lTOP &8- &b&lPunkty'
    46: ' &b1. &7{PTOP-POINTS-1}'
    47: ' &b2. &7{PTOP-POINTS-2}'
    48: ' &b3. &7{PTOP-POINTS-3}'
- cycles: 10
  cells:
    42: ' &b&lTOP &8- &b&lZabojstwa'
    46: ' &b1. &7{PTOP-KILLS-1}'
    47: ' &b2. &7{PTOP-KILLS-2}'
    48: ' &b3. &7{PTOP-KILLS-3}'
  header: '&7GitHub: &agithub.com/funnyguilds'
  footer: '&a&lWiadomosci braku (pokazujace sie, gdy gracz nie ma gildii)
   mozna zmienic w pliku messages.yml!'
```

### Informacja o "braku" (`messages.yml`)

Wszystkie informacje o braku gildii, topki, sojuszników, zastępców itd. możesz zmienić tutaj.

```yml
# <------- No Value Messages -------> #
gNameNoValue: Brak (G-NAME/NAME)
gTagNoValue: Brak (G-TAG/TAG)
gOwnerNoValue: Brak (G-OWNER)
gDeputiesNoValue: Brak (G-DEPUTIES)
gDeputyNoValue: Brak (G-DEPUTY)
gValidityNoValue: Brak (G-VALIDITY)
gRegionSizeNoValue: Brak (G-REGION-SIZE)
alliesNoValue: Brak (ALLIES)
enemiesNoValue: Brak (ENEMIES)
gtopNoValue: Brak (GTOP-x)
ptopNoValue: Brak (PTOP-x)
wgRegionNoValue: Brak (WG-REGION)
minMembersToIncludeNoValue: Brak (guild-min-members w config.yml)
```

### Ping wierszy (`tablist.yml`)

`player-list-ping:` dotyczy pingu wyświetlanego przy każdym wierszu tablisty.

```yml
# Liczba pingu pokazana przy każdej komorce.
cells-ping: 0
```

---

### Zapełnienie wierszy (`tablist.yml`)

`fill-cells:` — jeśli ustawione na `true`, wszystkie komórki graczy zostaną zapełnione, niezależnie od liczby graczy online.

```yml
# Czy wszystkie możliwe komórki maja zostać zapełnione, nie zważywszy na liczbę graczy online
fill-cells: true
```

---

### Aktywność tablisty (`tablist.yml`)

`enabled` — jeśli ustawione na `true`, tablista będzie działała; ustaw na `false`, jeśli nie chcesz, aby się wyświetlała.
`update-interval:` — czas, w jakim tablista ma aktualizować informacje.

:::note
Czas jest podawany w tickach! (20 ticków to 1 sekunda)
:::

```yml
# Czy tablista ma byc wlaczona
enabled: true
# Co ile tickow lista graczy powinna zostac odswiezona
update-interval: 20
```

---

### Kolor zmiennych (`tablist.yml`)

`use-relationship-colors:` — jeśli ustawione na `true`, kolory znaczników `{PTOP-%}` oraz `{GTOP-%}` będą zależne od relacji gildyjnych (neutralność, sojusz, wojna). Ustaw na `false`, jeśli nie chcesz takiej zależności.

```yml
# Czy zmienne typu {PTOP-%} oraz {GTOP-%} powinny byc pokolorowane w zaleznosci od relacji gildyjnych
use-relationship-colors: false
```

### PlaceholderAPI

FunnyGuilds wspiera dodatkowe znaczniki od [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/). Po zainstalowaniu wtyczki PlaceholderAPI możesz pobrać nowe znaczniki.

:::tip
Przykładowo, aby uzyskać znaczniki dotyczące gracza, wystarczy wpisać `/papi ecloud download Player`, a następnie `/papi reload`.

Po wykonaniu tej komendy wszystkie znaczniki, takie jak ilość HP `%player_health%`, będą już obsługiwane w tablist FunnyGuilds.
:::

Pełną listę możliwych znaczników i komend do nich znajdziesz w [PAPI-placeholders](https://github.com/PlaceholderAPI/PlaceholderAPI/wiki/Placeholders#papi-placeholders-1).

### Schemat numeracji tablisty

- `player-list-header` — nagłówek
- `player-list-footer` — stopka
- `Slot X` — wiersz nr X
