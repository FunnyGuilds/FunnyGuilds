Lista najczęściej zadawanych pytań dotyczących pluginu FunnyGuilds.

## Mgła przy wchodzeniu na teren gildii/opuszczaniu terenu gildii

W pliku `config.yml` zmień

```yaml
notification-boss-bar-flags:
- CREATE_FOG
```

na

```yaml
notification-boss-bar-flags: []
```

## Co to jest wersja nightly i gdzie ją mogę pobrać?

Wersje nightly to kompilacje pluginu zawierające wszystkie najnowsze zmiany w kodzie źródłowym. Oficjalne wydanie powstaje co kilka wersji nightly. Kolejne kompilacje są dostępne tutaj: [FunnyGuilds Nightly](https://ci.insertt.dev/job/FunnyGuilds/).

Po zainstalowaniu takiej wersji będzie się pojawiał komunikat o dostępności nowej wersji. Dzieje się tak, ponieważ updater uwzględnia wyłącznie oficjalne wydania — bez nightly. Taki komunikat można zignorować.

## Nie działają mi tagi, scoreboardy i punkty pod nickiem

Najczęstszą przyczyną tego typu błędów jest inny plugin korzystający ze scoreboardów i powiązanych z nimi elementów, takich jak tagi teamów nad głową czy punkty pod nickiem. Z uwagi na brak sensownego API po stronie Bukkita każdy plugin rejestruje własne scoreboardy, co bywa źródłem konfliktów. Przykładem jest Scoreboard Stats, który udostępnia opcję `compatibility mode` pozwalającą na poprawne współdziałanie. Jeżeli plugin nie ma podobnej opcji w konfiguracji, to jest niekompatybilny z FunnyGuilds.

## Jak zintegrować plugin z CombatLogX?

CombatLogX nie zabija graczy z uprawnieniami administratora/`op`, więc na takim koncie integracji nie da się przetestować. CombatLogX może też nadpisywać wiadomość wyświetlaną po śmierci, ustawioną w FunnyGuilds.
