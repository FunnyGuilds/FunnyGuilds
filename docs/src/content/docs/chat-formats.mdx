---
title: Formaty czatu
description: Znaczniki gildyjne dostępne w formatach czatu FunnyGuilds.
---

:::note
Podane niżej znaczniki wstaw w swój plugin od czatu.
:::

:::caution[Niekompatybilność z LPC]
Nie są one niestety wspierane przez plugin [LPC](https://www.spigotmc.org/resources/lpc-chat-formatter-1-7-10-1-19.68965/). Jednakże nie jesteśmy w stanie tego naprawić po naszej stronie — sam problem leży po stronie pluginu LPC, który używa złego priorytetu dla eventu od czatu, więc FunnyGuilds nie jest w stanie nadpisać placeholderów swoimi wartościami. Można jednak spróbować wykorzystać [PlaceholderAPI](/placeholderapi/).
:::

|            Znacznik            | Opis                                                                    |
| :-----------------------------: | :----------------------------------------------------------------------- |
|             `{POS}`             | Pokazuje, czy ktoś jest liderem, zastępcą lub zwykłym członkiem gildii    |
|             `{TAG}`             | Pokazuje TAG gildii, w przypadku braku jest pusty                        |
|            `{RANK}`             | Pokazuje, który gracz znajduje się w rankingu punktów                    |
| `{POINTS}` / `{POINTS-FORMAT}`  | Pokazuje ilość punktów gracza                                            |
