**FunnyGuilds** to konfigurowalny plugin gildyjny dla serwerów Minecraft
opartych na Paperze i Spigocie. Gracze zakładają gildie, przejmują tereny,
zawierają sojusze i rywalizują w rankingach; administrator konfiguruje każdy
z tych elementów osobno.
