:::note
Tylko gracze z odpowiednimi permisjami mogą używać komend z sekcji **Komendy dla Administratora**. Listę permisji znajdziesz w [Permisjach](/permissions/).
:::

## Komendy dla Administratora

### Ogólne

| Komenda | Opis |
| --- | --- |
| `/funnyguilds` | Sprawdza wersję FunnyGuilds. |
| `/funnyguilds reload` | Przeładowanie konfiguracji FunnyGuilds. |
| `/funnyguilds save-all` | Zapisz wszystko. |
| `/funnyguilds funnybin` | Zapisz konfigurację online (usprawnia pomoc na [GitHub Issues](https://github.com/FunnyGuilds/FunnyGuilds/issues)). |
| `/funnyguilds check` | Sprawdza czy jest dostępna nowa wersja FunnyGuilds. |

### Gildyjne

| Komenda | Opis |
| --- | --- |
| `/ga` | Wyświetla komendy gildyjne dla administratora. |
| `/ga dodaj <tag> <nick>` | Dodaje gracza do gildii. |
| `/ga usun <tag>` | Usuwa gildię. |
| `/ga wyrzuc <nick>` | Wyrzuca gracza z gildii. |
| `/ga tp <tag>` | Teleportuje do bazy gildii. |
| `/ga points <nick> <points>` | Ustawia liczbę punktów gracza. |
| `/ga kills <nick> <kills>` | Ustawia liczbę zabójstw gracza. |
| `/ga deaths <nick> <deaths>` | Ustawia liczbę śmierci gracza. |
| `/ga ban <tag> <czas> <powod>` | Banuje gildię na określony czas. |
| `/ga unban <tag>` | Odbanowuje gildię. |
| `/ga zycia <tag> <zycia>` | Ustawia liczbę żyć gildii. |
| `/ga ochrona <tag> <czas>` | Nadaje ochronę gildii. |
| `/ga przedluz <tag> <czas>` | Przedłuża ważność gildii o podany czas. |
| `/ga przenies <tag>` | Przenosi teren gildii. |
| `/ga nazwa <tag> <nazwa>` | Zmienia nazwę gildii. |
| `/ga tag <tag> <nowy tag>` | Zmienia tag gildii. |
| `/ga spy` | Szpieguje czat gildii. |
| `/ga enabled` | Zarządzanie statusem zakładania gildii. |
| `/ga lider <tag> <gracz>` | Zmienia lidera gildii. |
| `/ga zastepca <tag> <gracz>` | Nadaje zastępcę gildii. |
| `/ga baza <gracz>` | Teleportuje gracza do bazy jego gildii. |

## Komendy dla Gracza

### Informacyjne

| Komenda | Opis |
| --- | --- |
| `/gildia` `/gildie` `/g` | Wyświetla komendy gildyjne. |
| `/przedmioty` | Pokazuje przedmioty potrzebne do założenia gildii. |
| `/tnt` | Sprawdza czy TNT jest aktywne na terenach gildii. |
| `/info <tag>` | Informacje o danej gildii. |
| `/gracz <player>` | Informacje o danym graczu. |
| `/top` `/top10` | Wyświetla top 10 gildii. |
| `/ranking` | Wyświetla top 10 graczy. |

### Gildyjne

| Komenda | Opis |
| --- | --- |
| `/zaloz <tag> <name>` | Tworzy gildię. |
| `/usun` | Usuwa gildię. |
| `/potwierdz` | Potwierdza usunięcie gildii. |
| `/zapros <player>` | Zaprasza gracza do gildii. |
| `/dolacz <tag>` | Przyjmuje zaproszenie do gildii. |
| `/opusc` | Opuszcza gildię. |
| `/wyrzuc <player>` | Wyrzuca gracza z gildii. |
| `/baza` | Teleportuje do bazy gildii. |
| `/powieksz` | Powiększa teren gildii. |
| `/sojusz <tag>` | Pozwala nawiązać sojusz. |
| `/rozwiaz <tag>` | Rozwiązuje sojusz. |
| `/wojna <tag>` | Wyświetla komendy gildyjne. |
| `/przedluz` | Przedłuża ważność gildii. |
| `/lider <player>` | Oddaje założyciela gildii. |
| `/zastepca <player>` | Nadaje zastępcę gildii. |
| `/ustawbaze` `/ustawdom` | Ustawia dom gildii. |
| `/pvp [tag]` | Włącza i wyłącza pvp w gildii lub między sojusznikami. |
| `/ucieczka` `/escape` | Rozpoczyna ucieczkę z terenu innej gildii. |

### Inne
