---
title: Komendy
description: Pełna lista komend FunnyGuilds, pogrupowana według funkcji.
---

:::note
Komendy administratora (tabele oznaczone **Administrator**) wymagają
odpowiednich uprawnień — ich pełną listę znajdziesz w
[Uprawnieniach](/permissions/). Nazwy komend są w pełni konfigurowalne (sekcja
`commands` w `config.yml`) — poniżej podano wartości domyślne.
:::

## Ogólne

| Komenda | Opis |
|---|---|
| `/funnyguilds` `/fg` | Sprawdza wersję FunnyGuilds. |
| `/funnyguilds reload` `/funnyguilds rl` | Przeładowuje konfigurację FunnyGuilds. |
| `/funnyguilds save-all` | Zapisuje wszystkie dane. |
| `/funnyguilds funnybin` | Wysyła konfigurację online (ułatwia uzyskanie pomocy na [GitHub Issues](https://github.com/FunnyGuilds/FunnyGuilds/issues)). |
| `/funnyguilds check` `/funnyguilds update` | Sprawdza dostępność nowej wersji. |
| `/gildia` `/gildie` `/g` | Wyświetla listę komend gildyjnych. |

## Gildie

Patrz [Gildie](/guilds/) — zakładanie, członkostwo, ważność i rozwiązywanie.

| Komenda | Opis |
|---|---|
| `/zaloz <tag> <nazwa>` | Zakłada gildię. |
| `/usun` `/potwierdz` | Rozwiązuje gildię (dwuetapowo). |
| `/zapros <gracz>` `/zapros *` | Zaprasza gracza (lub wszystkich w promieniu). |
| `/dolacz <tag>` | Przyjmuje zaproszenie do gildii. |
| `/opusc` | Opuszcza gildię. |
| `/wyrzuc <gracz>` | Wyrzuca gracza z gildii. |
| `/lider` `/zalozyciel` `<gracz>` | Przekazuje przywództwo gildii. |
| `/zastepca <gracz>` | Nadaje/odbiera rangę zastępcy. |
| `/przedluz` | Przedłuża ważność gildii. |
| `/przedmioty` | Pokazuje przedmioty potrzebne do założenia gildii. |
| `/info <tag>` | Wyświetla informacje o gildii. |
| `/gracz <gracz>` | Wyświetla informacje o graczu. |

| Administrator | Opis |
|---|---|
| `/ga dodaj <tag> <gracz>` | Dodaje gracza do gildii. |
| `/ga usun <tag>` | Usuwa gildię. |
| `/ga wyrzuc <gracz>` | Wyrzuca gracza z gildii. |
| `/ga nazwa <tag> <nazwa>` | Zmienia nazwę gildii. |
| `/ga tag <tag> <nowy tag>` | Zmienia tag gildii. |
| `/ga lider <tag> <gracz>` | Zmienia lidera gildii. |
| `/ga zastepca <tag> <gracz>` | Nadaje/odbiera graczowi rangę zastępcy. |
| `/ga przedluz <tag> <czas>` | Przedłuża ważność gildii o podany czas. |
| `/ga enabled` | Włącza/wyłącza możliwość zakładania gildii. |
| `/ga ban <tag> <czas> <powod>` | Banuje gildię na określony czas. |
| `/ga unban <tag>` | Odbanowuje gildię. |
| `/ga items <gracz> <typ>` | Wydaje graczowi zestaw przedmiotów danego typu (`guild`, `base`, `join`, `enlarge`, `validity`, `rankReset`, `statsReset`, `firstGuildReward`). |

## Tereny

Patrz [Tereny i ochrona](/territories/) — serce, powiększanie, ochrona, TNT.

| Komenda | Opis |
|---|---|
| `/baza` | Teleportuje do bazy gildii. |
| `/ustawbaze` `/ustawdom` | Ustawia bazę (home) gildii. |
| `/powieksz` | Powiększa teren gildii. |
| `/ucieczka` `/escape` | Rozpoczyna ucieczkę z cudzego terenu. |
| `/tnt` | Sprawdza, czy TNT jest aktywne na terenach gildii. |

| Administrator | Opis |
|---|---|
| `/ga tp <tag>` | Teleportuje do bazy gildii. |
| `/ga baza <gracz>` | Teleportuje gracza do bazy jego gildii. |
| `/ga przenies <tag>` | Przenosi teren gildii. |
| `/ga ochrona <tag> <czas>` | Nadaje gildii ochronę na podany czas. |

## Sojusze i wojny

Patrz [Sojusze i wojny](/alliances-wars/).

| Komenda | Opis |
|---|---|
| `/sojusz <tag>` | Proponuje/akceptuje sojusz. |
| `/rozwiaz <tag>` | Rozwiązuje sojusz. |

| `/ga zycia <tag> <zycia>` | Ustawia liczbę żyć gildii. |

## Rankingi i walka

Patrz [Rankingi i walka](/rankings-combat/). Topki graczy i gildii nie mają
własnych komend — wyświetla się je za pomocą placeholderów `{PTOP-…}` i
`{GTOP-…}` (patrz [Placeholdery](/placeholders/)), na przykład na tabliście.

| Komenda | Opis |
|---|---|
| `/rankreset` `/resetrank` | Resetuje ranking gracza. |
| `/statsreset` `/resetstats` | Resetuje statystyki gracza. |

| Administrator | Opis |
|---|---|
| `/ga points <gracz> <points>` | Ustawia liczbę punktów gracza. |
| `/ga kills <gracz> <kills>` | Ustawia liczbę zabójstw gracza. |
| `/ga deaths <gracz> <deaths>` | Ustawia liczbę śmierci gracza. |
| `/ga logouts <gracz> <logouts>` | Ustawia liczbę wylogowań gracza podczas walki. |
| `/ga assists <gracz> <assists>` | Ustawia liczbę asyst gracza. |
