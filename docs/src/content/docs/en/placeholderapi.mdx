:::tip[Adding your own placeholders]
If you want to use placeholders in your own plugin using PlaceholderAPI, check out this guide: [Adding placeholders to PlaceholderAPI](https://github.com/PlaceholderAPI/PlaceholderAPI/wiki/Hook-into-PlaceholderAPI#adding-placeholders-to-placeholderapi).
:::

FunnyGuilds' placeholders can be used in any other plugin that supports [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/).
