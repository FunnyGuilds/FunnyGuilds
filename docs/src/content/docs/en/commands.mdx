Only players with the appropriate permissions can use commands from the **Admin Commands** section. You can find the list of permissions in [Permissions](/en/permissions/).
:::

## Admin Commands

### General

| Command | Description |
| --- | --- |
| `/funnyguilds` | Checks the FunnyGuilds version. |
| `/funnyguilds reload` | Reloads the FunnyGuilds configuration. |
| `/funnyguilds save-all` | Saves everything. |
| `/funnyguilds funnybin` | Uploads the configuration online (makes it easier to get help at [GitHub Issues](https://github.com/FunnyGuilds/FunnyGuilds/issues)). |
| `/funnyguilds check` | Checks whether a new FunnyGuilds version is available. |

### Guild

| Command | Description |
| --- | --- |
| `/ga` | Shows the guild admin commands. |
| `/ga dodaj <tag> <nick>` | Adds a player to a guild. |
| `/ga usun <tag>` | Deletes a guild. |
| `/ga wyrzuc <nick>` | Kicks a player from their guild. |
| `/ga tp <tag>` | Teleports to a guild's base. |
| `/ga points <nick> <points>` | Sets a player's point count. |
| `/ga kills <nick> <kills>` | Sets a player's kill count. |
| `/ga deaths <nick> <deaths>` | Sets a player's death count. |
| `/ga ban <tag> <time> <reason>` | Bans a guild for a specified duration. |
| `/ga unban <tag>` | Unbans a guild. |
| `/ga zycia <tag> <lives>` | Sets a guild's number of lives. |
| `/ga ochrona <tag> <time>` | Grants protection to a guild. |
| `/ga przedluz <tag> <time>` | Extends a guild's validity by the given time. |
| `/ga przenies <tag>` | Moves a guild's territory. |
| `/ga nazwa <tag> <name>` | Renames a guild. |
| `/ga tag <tag> <new tag>` | Changes a guild's tag. |
| `/ga spy` | Spies on guild chat. |
| `/ga enabled` | Manages whether guild creation is enabled. |
| `/ga lider <tag> <player>` | Changes a guild's leader. |
| `/ga zastepca <tag> <player>` | Grants a player deputy status in a guild. |
| `/ga baza <player>` | Teleports a player to their guild's base. |

## Player Commands

### Informational

| Command | Description |
| --- | --- |
| `/gildia` `/gildie` `/g` | Shows the guild commands. |
| `/przedmioty` | Shows the items needed to create a guild. |
| `/tnt` | Checks whether TNT is active on guild territories. |
| `/info <tag>` | Information about a given guild. |
| `/gracz <player>` | Information about a given player. |
| `/top` `/top10` | Shows the top 10 guilds. |
| `/ranking` | Shows the top 10 players. |
