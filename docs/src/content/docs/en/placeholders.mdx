---
title: Placeholders
description: List of built-in FunnyGuilds placeholders and what they mean.
---

FunnyGuilds has many built-in placeholders. Below is the full list, together with what each one returns.

A `@Deprecated` note next to a placeholder means it may be removed in the future and should not be used. A replacement is usually listed alongside it.

## Player Placeholders
### - Basic -

|   Placeholder    | Description                                                                                                                                |
|:----------------:|:---------------------------------------------------------------------------------------------------------------------------------------------|
| `PLAYER`/`NAME`  | Returns the player's nickname                                                                                                              |
|      `PING`      | Returns the player's current ping                                                                                                          |
|     `WORLD`      | Returns the name of the world the player is currently in                                                                                   |
|     `ONLINE`     | Returns the number of online players visible to this player (not counting players they can't see themselves — for example those in vanish) |
|   `HAS-GUILD`    | Returns whether the player belongs to a guild                                                                                              |

### - Ranking -

|        Placeholder        | Description                                                                                                                                                          |
|:-------------------------:|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|         `POINTS`          | Returns the player's current ranking points                                                                                                                          |
|          `KILLS`          | Returns the player's current kill count                                                                                                                              |
|         `DEATHS`          | Returns the player's current death count                                                                                                                             |
|         `ASSISTS`         | Returns the player's current assist count                                                                                                                            |
|         `LOGOUTS`         | Returns the player's current count of logouts during combat                                                                                                          |
|           `KDR`           | Returns the player's KDR (kills / deaths)                                                                                                                            |
|           `KDA`           | Returns the player's KDA ((kills + assists) / deaths)                                                                                                                |
| **Deprecated** `POSITION` | Returns the player's position in the ranking-points top list. We recommend using the `POSITION-<type>` placeholder described below instead                            |
|     `POSITION-<type>`     | The player's position in the top list of the given type (e.g. `DEATHS`). The available (and currently enabled) types are listed under `top.enabled-user-tops` in `config.yml`. |
|     `GUILD-POSITION`      | The position of the player's guild in the guild top list                                                                                                             |

### - Top lists -

Player (`PTOP`) and guild (`GTOP`) top lists always require both a **type** and a **position**:

|        Placeholder        | Description                                                                       |
|:-------------------------:|:------------------------------------------------------------------------------------|
| `PTOP-<type>-<position>`  | The player at the given position in the top list of that type (e.g. `{PTOP-KILLS-1}`, `{PTOP-POINTS-10}`) |
| `GTOP-<type>-<position>`  | The guild at the given position in the top list of that type (e.g. `{GTOP-AVG_POINTS-1}`)                 |

By default this returns the player's nickname (or the guild's name) along with the value. You can narrow it down by appending one of these suffixes:

| Suffix   | `PTOP`               | `GTOP`              |
|:---------|:---------------------|:--------------------|
| `-NAME`  | The player's name    | The guild's name    |
| `-TAG`   | —                    | The guild's tag     |
| `-UUID`  | The player's UUID    | —                   |
| `-VALUE` | The value alone      | The value alone     |

For example, `{PTOP-POINTS-1-NAME}` returns just the nickname at the top of the points list, and `{GTOP-KILLS-1-TAG}` returns just the tag of the best guild.

:::note[Top list types]
The available (and currently enabled) types are listed under `top.enabled-user-tops` and
`top.enabled-guild-tops` in `config.yml` — see [Rankings & combat](/en/rankings-combat/).
:::

## - Additional external integrations -
