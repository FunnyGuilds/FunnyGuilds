## Requirements

- A **[Paper](https://papermc.io/)** server (or a compatible fork, e.g. Purpur).
- Supported Minecraft versions: **1.8 – 1.21.x**.
- A **Java** version compatible with your server version.

:::tip[Optional plugins]
FunnyGuilds works on its own, but it can integrate with other plugins — see
[Integrations](#integrations) below.
:::

## Download

See the [Download](/en/download/) page for a link to the 5.x nightly build
and the latest stable 4.x release.

:::note
FunnyGuilds 5.x is currently available only as a nightly build. After downloading it
you may see a message about a newer version being available — this is expected, as
the updater only tracks official releases.
:::

## Step by step

<Steps>

1. Download the `FunnyGuilds-x.x.x.jar` file.
2. Drop it into the `plugins/` directory on your server.
3. Start (or restart) the server — the plugin generates its configuration files.
4. Adjust the settings in `plugins/FunnyGuilds/config.yml` — see [Configuration](/en/configuration/).
5. Apply the changes with `/funnyguilds reload` (no server restart required).

</Steps>

## Integrations

FunnyGuilds automatically detects and uses the following plugins when they are
installed:

| Plugin | Used for |
|---|---|
| [WorldEdit](https://dev.bukkit.org/projects/worldedit) | Region operations |
| [WorldGuard](https://dev.bukkit.org/projects/worldguard) | Protection and regions |
| [Vault](https://dev.bukkit.org/projects/vault) | Economy |
| [PlaceholderAPI](https://www.spigotmc.org/resources/6245/) | Placeholders — see the [integration docs](/en/placeholderapi/) |
| [dynmap](https://github.com/webbukkit/dynmap) | Guild markers on the map |
| [DecentHolograms](https://www.spigotmc.org/resources/96927/) | Ranking holograms |
