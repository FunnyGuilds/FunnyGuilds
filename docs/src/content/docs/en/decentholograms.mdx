---
title: DecentHolograms
description: The guild heart hologram, powered by DecentHolograms.
---

FunnyGuilds doesn't render the hologram itself — it requires
[DecentHolograms](https://www.spigotmc.org/resources/96927/) to be installed.
Without that plugin, the feature is simply inactive. Hologram configuration
lives under `heart-configuration.hologram` (see also
[Territories & protection](/en/territories/#guild-heart)):

```yaml
heart-configuration:
  hologram:
    enabled: true
    update-interval: 400
    item: AIR
    location-correction: {x: 0.5, y: 2.5, z: 0.5}
    displayed-lines:
    - '&7&m-------------------'
    - '&7- &bFunnyGuilds &7-'
    - '&7- &bGuild {TAG} &7-'
    - '&7- &bLives {LIVES} &7-'
    - '&7&m-------------------'
```

`item` is an optional decorative icon shown above the text (leave it `AIR`
to disable). `update-interval` is the refresh rate in ticks.
`displayed-lines` supports a rich set of guild variables — `{TAG}`,
`{OWNER}`, `{MEMBERS-ONLINE}`/`{MEMBERS-ALL}`, `{LIVES}`/`{LIVES-SYMBOL}`,
`{AVG-POINTS}`, `{VALIDITY}`/`{VALIDITY-TIME}`, `{ALLIES}`/`{ENEMIES}` and
more — the same set used in [dynmap](/en/dynmap/) labels.
