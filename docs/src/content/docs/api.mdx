### FunnyGuilds

Główna instancja pluginu. Powinna zostać pobrana tylko raz, np.:

```java
public class MyPlugin extends JavaPlugin {

    private FunnyGuilds funnyGuilds;
    
    @Override
    public void onEnable() {
        funnyGuilds = FunnyGuilds.getInstance();
    }
    
}
```

### User

Dostępne metody pobierania użytkownika:

- `UserManager#findByName(String)`
- `UserManager#findByPlayer(Player)`
- `UserManager#findByUuid(UUID)`

Przykład użycia:

```java
UserManager userManager = funnyGuilds.getUserManager();
Optional<User> userOption = userManager.findByName("PlayerName");

if (userOption.isPresent()) {
    User user = userOption.orElseThrow();
}
```

`UserManager#addUser(User)` odrzuca inny obiekt z już zarejestrowanym UUID,
rzucając `IllegalStateException`. Istniejący obiekt użytkownika oraz oba indeksy
pozostają bez zmian. Po odrzuceniu nie używaj przekazanego obiektu jako
zarejestrowanego użytkownika; istniejące konto pobierz przez `findByUuid(UUID)`.

### Guild

Dostępne metody pobierania gildii:

- `GuildManager#findByName(String)`
- `GuildManager#findByTag(String)`
- `GuildManager#findByUuid(UUID)`
- `User#getGuild()`

Kolekcje członków, zastępców, sojuszników, wrogów i ustawień PvP sojuszy
są dostępne do odczytu. Wprowadzaj zmiany przez metody `Guild`, takie jak
`addMember` i `removeAlly`, aby zostały uwzględnione w zapisie.
`Guild#getHome()` i `Region#getCenter()` zwracają kopie lokalizacji.

Przykład użycia:

```java
GuildManager guildManager = funnyGuilds.getGuildManager();
Optional<Guild> guildOption = guildManager.findByTag("TAG");

if (guildOption.isPresent()) {
    Guild guild = guildOption.orElseThrow();
}
```

```java
Optional<Guild> guildOption = user.getGuild();

if (guildOption.isPresent()) {
    Guild guild = guildOption.orElseThrow();
}
```

### Role i uprawnienia gildyjne

- `FunnyGuilds#getGuildPermissionChecker()` udostępnia
  `getStoredDecision(guild, user, permission)` z wartością i źródłem.
  `handlePermission` i `handleProtectionPermission` uwzględniają też
  zdarzenia integracji podczas wykonywania akcji.
- `FunnyGuilds#getGuildRoleService()` tworzy i przypisuje role oraz edytuje prawa,
  wyjątki i zakres delegowania. Zmianę wykonuj w głównym wątku i przekaż
  wykonawcę do sprawdzenia. `GuildRoleChangeEvent` udostępnia politykę
  sprzed zmiany i po jej zatwierdzeniu.

### Komendy rozszerzeń

Moduły w `extensions/` mogą zgłaszać komendy przy starcie przez
`ExtensionCommands` z `:extensions:api`. Moduł podaje stałe ID w formacie
`nazwa-modułu.nazwa-komendy`, domyślną nazwę, aliasy i instancję klasy z adnotacjami
`@FunnyComponent` oraz `@FunnyCommand`. W adnotacji używa parametrów
`${extension.<id>.name}` i `${extension.<id>.aliases}`. Uprawnienie Bukkit
deklaruje w adnotacji komendy.

Nowy moduł podpina się w kodzie startowym `:plugin`, który przekazuje rejestr
metodzie modułu `registerCommands`. Moduł tworzy instancje komend i przekazuje
im ich zależności. Wspólna konfiguracja instaluje te komendy przy starcie
serwera. Panel korzysta z tej ścieżki dla `guild-panel.panel`. Samo GUI można
otworzyć w głównym wątku przez `FunnyGuilds#getPanelModule().open(player)`.
Wywołujący odpowiada za sprawdzenie prawa dostępu do swojego punktu wejścia.

### Przedmioty i wymagania

Konfiguracja przedmiotów z `items.yml` jest dostępna bezpośrednio z instancji pluginu:

- `FunnyGuilds#getItemsConfiguration()` — biblioteka przedmiotów i zestawy wymagań.
- `FunnyGuilds#getGuildItemSetService()` — zestaw przysługujący danemu graczowi.
- `FunnyGuilds#getGuildItemRequirementChecker()` — sprawdzenie, czy gracz spełnia wymagania.

Wydarzenia dotyczące:
- zmian rankingu: [net/dzikoysk/funnyguilds/event/rank](https://github.com/FunnyGuilds/FunnyGuilds/tree/5.x/plugin/src/main/java/net/dzikoysk/funnyguilds/event/rank)
- gildii: [net/dzikoysk/funnyguilds/event/guild](https://github.com/FunnyGuilds/FunnyGuilds/tree/5.x/plugin/src/main/java/net/dzikoysk/funnyguilds/event/guild)
- członków gildii: [net/dzikoysk/funnyguilds/event/guild/member](https://github.com/FunnyGuilds/FunnyGuilds/tree/5.x/plugin/src/main/java/net/dzikoysk/funnyguilds/event/guild/member)
- sojuszy: [net/dzikoysk/funnyguilds/event/guild/ally](https://github.com/FunnyGuilds/FunnyGuilds/tree/5.x/plugin/src/main/java/net/dzikoysk/funnyguilds/event/guild/ally)

Przykład z użyciem `GuildDeleteEvent`:

```java
public class GuildDeleteListener implements Listener {

    @EventHandler
    public void onGuildDelete(GuildDeleteEvent event) {
        Guild guild = event.getGuild();
        User doer = event.getDoer();
        FunnyEvent.EventCause eventCause = event.getEventCause();

    }
    
}
```

Rejestracja w metodzie `onEnable()`:

```java
@Override
public void onEnable() {
    this.getServer().getPluginManager().registerEvents(new GuildDeleteListener(), this);
}
```
