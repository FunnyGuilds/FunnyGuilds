### FunnyGuilds

Główna instancja pluginu. Powinna zostać pobrana tylko raz, np.:

```java
public class MyPlugin extends JavaPlugin {

    private FunnyGuilds funnyGuilds;
    
    @Override
    public void onEnable() {
        funnyGuilds = FunnyGuilds.getInstance();
    }
    
}
```

### User

Dostępne metody pobierania użytkownika:

- `UserManager#findByName(String)`
- `UserManager#findByPlayer(Player)`
- `UserManager#findByUuid(UUID)`

Przykład użycia:

```java
UserManager userManager = funnyGuilds.getUserManager();
Option<User> userOption = userManager.findByName("PlayerName");

if (userOption.isPresent()) {
    User user = userOption.get();
}
```

### Guild

Dostępne metody pobierania gildii:

- `GuildManager#findByName(String)`
- `GuildManager#findByTag(String)`
- `GuildManager#findByUuid(UUID)`
- `User#getGuild()`

Przykład użycia:

```java
GuildManager guildManager = funnyGuilds.getGuildManager();
Option<Guild> guildOption = guildManager.findByTag("TAG");

if (guildOption.isPresent()) {
    Guild guild = guildOption.get();
}
```

```java
Option<Guild> guildOption = user.getGuild();

if (guildOption.isPresent()) {
    Guild guild = guildOption.get();
}
```

### Nasłuchiwanie wydarzeń

Wydarzenia dotyczące:
- zmian rankingu: [net/dzikoysk/funnyguilds/event/rank](https://github.com/FunnyGuilds/FunnyGuilds/tree/master/plugin/src/main/java/net/dzikoysk/funnyguilds/event/rank)
- gildii: [net/dzikoysk/funnyguilds/event/guild](https://github.com/FunnyGuilds/FunnyGuilds/tree/master/plugin/src/main/java/net/dzikoysk/funnyguilds/event/guild)
- członków gildii: [net/dzikoysk/funnyguilds/event/guild/member](https://github.com/FunnyGuilds/FunnyGuilds/tree/master/plugin/src/main/java/net/dzikoysk/funnyguilds/event/guild/member)
- sojuszy: [net/dzikoysk/funnyguilds/event/guild/ally](https://github.com/FunnyGuilds/FunnyGuilds/tree/master/plugin/src/main/java/net/dzikoysk/funnyguilds/event/guild/ally)

Przykład z użyciem `GuildDeleteEvent`:

```java
public class GuildDeleteListener implements Listener {

    @EventHandler
    public void onGuildDelete(GuildDeleteEvent event) {
        Guild guild = event.getGuild();
        User doer = event.getDoer();
        FunnyEvent.EventCause eventCause = event.getEventCause();

    }
    
}
```

Rejestracja w metodzie `onEnable()`:

```java
@Override
public void onEnable() {
    this.getServer().getPluginManager().registerEvents(new GuildDeleteListener(), this);
}
```
