# FunnyGuilds Tribute (#4.0)

- **Tag:** 4.0.0.0
- **Published:** 2017-10-14T14:44:35Z
- **GitHub release:** https://github.com/FunnyGuilds/FunnyGuilds/releases/tag/4.0.0.0

---

Zgodnie ze założeniami zapowiedzianymi w poprzednim release - **począwszy od tej chwili**, wszystkie wersje pluginu starsze niż 4.0, **nie będą** wspierane.

**Uwagi**
* Wersja 4.x dodaje wsparcie dla wielu wersji silnika, zmienia też wiele starszych elementów. Może to powodować błędy, dlatego nie zaleca się używania obecnej wersji rozwojowej na oficjalnych serwerach.

**Zmiany:**
* Aktualizacja pluginu ze wsparciem do najnowszej wersji gry;
* Dodanie wsparcia dla tabeli graczy (podziękowania dla @insertt), dzięki czemu nie trzeba korzystać z jakiś pobocznych pluginów i innych wodotrysków;
* Dodano możliwość customizacji pingu na tabeli graczy;
* Naprawiono pomniejsze błędy i konflikty.

**Wymagania:**
* Craftbukkit 1.8+
* Java 8
