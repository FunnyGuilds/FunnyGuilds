**Uwagi**
* Wersja 4.x dodaje wsparcie dla wielu wersji silnika, zmienia też wiele starszych elementów. Może to powodować błędy, dlatego nie zaleca się używania obecnej wersji rozwojowej na oficjalnych serwerach.

**Zmiany:**
* Zaimplementowanie nowego stylu konfiguracji tab listy (#550);
* Poprawki dot. tab listy;
* Zmiana host'a updatera.

**Wymagania:**
* Craftbukkit 1.8+
* Java 8
